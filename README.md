## ✨ 주요 특징 (Features)

### 🧩 컴포넌트 기반 구조
- 재사용성 높은 React 컴포넌트 설계
- Project Modal, Tags, Timeline 등 구조적 아키텍처 적용

### 📂 데이터 기반 UI
- 프로젝트·학력·스킬 정보를 별도 JSON 객체로 관리
- 유지보수 용이 & 데이터 변경 시 자동 반영

### 📱 반응형 디자인
- Desktop · Tablet · Mobile 전 기기 대응<br><br>

## 📂 프로젝트 구조
```bash
📦 portfolio
 src/
 ├── assets/           # 이미지 및 리소스
 ├── components/       # 재사용 컴포넌트
 ├── data/             # 프로젝트/학력/스킬 데이터
 ├── views/            # 각 화면(Home 등)
 ├── styles/           # SCSS 스타일
 ├── App.jsx
 └── index.jsx
```
